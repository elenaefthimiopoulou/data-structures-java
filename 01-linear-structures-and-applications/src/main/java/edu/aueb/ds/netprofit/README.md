# Μέρος Γ: Εφαρμογή Υπολογισμού Καθαρού Κέρδους Μετοχών

Αυτό το πακέτο (`edu.aueb.ds.netprofit`) περιέχει την εφαρμογή για τον υπολογισμό του συνολικού καθαρού κέρδους από μια σειρά συναλλαγών αγοράς και πώλησης μετοχών.

---

## 1. Περιγραφή Εργασίας

### Στόχος

Ο στόχος είναι η δημιουργία ενός προγράμματος (`NetProfit.java`) που διαβάζει μια σειρά από συναλλαγές μετοχών (αγορές και πωλήσεις) από ένα αρχείο και υπολογίζει το συνολικό καθαρό κέρδος ή ζημιά.

### Το Λογιστικό Πρόβλημα

Το πρόγραμμα πρέπει να ακολουθεί την λογιστική αρχή ότι οι πρώτες μετοχές που αγοράστηκαν θεωρούνται οι πρώτες που πωλούνται.

**Παράδειγμα Υπολογισμού:**
Για παράδειγμα, έστω ότι την χρονική στιγμή t1 αγοράσαμε 40 μετοχές από κάποια εταιρεία, σε τιμή 25.2 ευρώ.
Μετέπειτα, τη χρονική στιγμή t2, αγοράσαμε άλλες 30 μετοχές από την ίδια εταιρεία σε τιμή 21.8 ευρώ, και τη χρονική στιγμή t3, αγοράσαμε ακόμα 50 μετοχές σε τιμή 34.4 ευρώ.
Έστω ότι αργότερα πουλάμε 100 μετοχές (από τις 120 που έχουμε) σε τιμή 30 ευρώ.
Η λογιστική αρχή που χρησιμοποιείται για να καθορίσουμε το καθαρό κέρδος της πώλησης εκείνη τη στιγμή στηρίζεται στην ιδέα ότι οι μετοχές που πουλάμε θεωρούμε ότι είναι αυτές που αγοράστηκαν πιο νωρίς.
Τα περισσότερα λογισμικά διαχείρισης επενδυτικών χαρτοφυλακίων χρησιμοποιούν αυτή την αρχή.
Στο παράδειγμά μας, αυτό σημαίνει ότι από τις 100 μετοχές που πουλάμε, θεωρούμε ότι οι πρώτες 40 προέρχονται από αυτές που αγοράστηκαν πιο νωρίς, δηλαδή την στιγμή t1, οι επόμενες 30 από αυτές που αγοράστηκαν την στιγμή t2, και οι επόμενες 30 από την τελευταία αγορά.
Ας το δούμε αναλυτικά:

Γράφουμε αναλυτικά τις αγορές που εκτελέστηκαν με τη σωστή χρονική σειρά:
1.  `buy 40 price 25.2`
2.  `buy 30 price 21.8`
3.  `buy 50 price 34.4`

Αν ακολουθήσει η πώληση `sell 100 price 30`, το κέρδος υπολογίζεται "εξαντλώντας" τις παρτίδες με τη σειρά που αγοράστηκαν:
-   Από την 1η αγορά: `40 * (30 - 25.2) = 192`
-   Από την 2η αγορά: `30 * (30 - 21.8) = 246`
-   Από την 3η αγορά: `30 * (30 - 34.4) = -132`

Έτσι το καθαρό κέρδος μας εκείνη τη στιγμή θεωρούμε ότι υπολογίζεται ως εξής:

**Συνολικό καθαρό κέρδος:** `192 + 246 - 132 = 306`. Το πρόγραμμα πρέπει να εκτυπώσει το τελικό αποτέλεσμα στη μορφή: `Total net profit: 306.0`.

### Ζητούμενα

Τα παραδοτέα για αυτό το μέρος της εργασίας είναι:
-   Το αρχείο `NetProfit.java` με την υλοποίηση του προγράμματος.
-   Ένα αρχείο `implementation.md` που εξηγεί λεπτομερώς τον αλγόριθμο και τις επιλογές υλοποίησης.

Το μονοπάτι προς το αρχείο εισόδου πρέπει να δίνεται ως όρισμα γραμμής εντολών. Για παράδειγμα:
```bash
  java edu.aueb.ds.netprofit.NetProfit path/to/file.txt
```

## 2. Ανάγνωση και Ανάλυση Αρχείου Εισόδου

Για την ανάγνωση του αρχείου συναλλαγών, μια καλή προσέγγιση είναι η χρήση των κλάσεων `java.io.BufferedReader` και `java.io.FileReader`.

**Σημαντική Σημείωση:** Θεωρούμε ότι σε όλες τις έγκυρες γραμμές του αρχείου εισόδου, το πλήθος των μετοχών είναι **ακέραιος** αριθμός και οι τιμές είναι **πραγματικοί** αριθμοί (`double`).

**Γενικά Βήματα που πρέπει να σκεφτείτε:**

1.  **Διάβασμα Γραμμών:** Πώς μπορείτε να διαβάσετε το αρχείο γραμμή προς γραμμή μέχρι να φτάσετε στο τέλος του;
2.  **Ανάλυση Γραμμής:** Αφού έχετε μια γραμμή ως `String`, πώς μπορείτε να την "σπάσετε" στα συστατικά της μέρη;
3.  **Μετατροπή Τύπων:** Πώς θα μετατρέψετε την ποσότητα και την τιμή από `String` στους κατάλληλους αριθμητικούς τύπους;

**Σκελετός Κώδικα Ανάγνωσης:**
```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;
import java.util.NoSuchElementException;

//...
        
try (BufferedReader reader = new BufferedReader(new FileReader(filePath))) {
    String line;
    while ((line = reader.readLine()) != null) {
        String[] parts = line.split(" ");
        if (parts.length != 4) {
                continue; // Ignore malformed lines
        }
        
        // Λογική parsing των μερών της εισόδου (parts)... 
        
        // Η λογική για την ανάλυση της κάθε γραμμής έρχεται εδώ...
    }
} catch (IOException e) {
    // Χειρισμός σφαλμάτων που σχετίζονται με το αρχείο.
} catch (NumberFormatException e) {
    // Χειρισμός σφαλμάτων που σχετίζονται με το format της εισόδου.
}
```

## 3. Διαχείριση Σφαλμάτων
Το πρόγραμμα πρέπει να είναι ανθεκτικό και να διαχειρίζεται σωστά τις παρακάτω περιπτώσεις σφαλμάτων, τυπώνοντας τα ακριβή μηνύματα λάθους:

-   **Δεν Δόθηκε Αρχείο Εισόδου:** `Usage: java NetProfit <path_to_text_file>`
-   **Το Αρχείο δεν Βρέθηκε (`IOException`):** `Error: Could not read file '<file_path>'. <error_details>`
-   **Προσπάθεια Πώλησης Μη Επαρκών Μετοχών:** `Error: Attempting to sell X shares, but only Y are available.`
-   **Μη Έγκυρη Μορφή Αριθμού (`NumberFormatException`):** `Error: Invalid number format in the input file.`
-   **Λανθασμένα Μορφοποιημένες Γραμμές:** Το πρόγραμμα πρέπει να αγνοήσει σιωπηλά την ελαττωματική γραμμή και να συνεχίσει.

> **Tip:** Για να δείτε το ακριβές μήνυμα εξόδου που αναμένεται για κάθε περίπτωση, μελετήστε το αρχείο `src/test/resources/net_profit_test_cases/solutions.txt`.
