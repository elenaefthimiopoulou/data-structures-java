# Μέρος Α: Υλοποίηση Στοίβας (Stack) και Ουράς (Queue)

Αυτό το πακέτο (`edu.aueb.ds.datastructures`) περιέχει τις υλοποιήσεις των βασικών δομών δεδομένων που αποτελούν τον πυρήνα της εργασίας.

---

## Περιγραφή Εργασίας

### Στόχος

Ο στόχος είναι η υλοποίηση των δομών δεδομένων της Στοίβας (Stack) και της Ουράς (Queue), χρησιμοποιώντας ως βάση μια δομή Μονής Συνδεδεμένης Λίστας (Single Linked List).

### Οδηγίες Υλοποίησης

*   **Generics:** Όλες οι δομές πρέπει να χρησιμοποιούν Generics για να λειτουργούν με οποιονδήποτε τύπο αντικειμένων.
*   **Αποδοτικότητα:** Όλες οι μέθοδοι εισαγωγής, εξαγωγής και η `size()` πρέπει να εκτελούνται σε σταθερό χρόνο **O(1)**.
*   **Διαχείριση Σφαλμάτων:** Όταν μια στοίβα ή ουρά είναι κενή, οι μέθοδοι που προσπαθούν να διαβάσουν ή να αφαιρέσουν στοιχεία (`pop`, `peek`, `get`) πρέπει να προκαλούν μια εξαίρεση τύπου **`NoSuchElementException`**. Η εξαίρεση **`NoSuchElementException`** ανήκει στην core βιβλιοθήκη της Java. Κάντε την import από το πακέτο `java.util`. Μην κατασκευάσετε δική σας εξαίρεση.
*   **Περιορισμοί:** Δεν επιτρέπεται η χρήση έτοιμων υλοποιήσεων δομών από τη βιβλιοθήκη της Java (π.χ., `ArrayList`, `LinkedList`).

### Ζητούμενα

1.  **`ListImpl.java`**: Ολοκλήρωση της υλοποίησης της διεπαφής `List.java` ως απλά συνδεδεμένη λίστα.
2.  **`StackImpl.java`**: Υλοποίηση της διεπαφής `Stack.java` χρησιμοποιώντας τη λίστα, με όλες τις βασικές λειτουργίες (`push`, `pop`, `peek`, `size`) να έχουν πολυπλοκότητα **O(1)**.
3.  **`QueueImpl.java`**: Υλοποίηση της διεπαφής `Queue.java` χρησιμοποιώντας τη λίστα, με όλες τις βασικές λειτουργίες (`put`, `get`, `peek`, `size`) να έχουν πολυπλοκότητα **O(1)**.


### Αρχεία στο Πακέτο

-   **`Node.java`**: Αναπαριστά έναν κόμβο σε μια συνδεδεμένη λίστα.
-   **`List.java`**: Η διεπαφή (interface) για τη συνδεδεμένη λίστα.
-   **`ListImpl.java`**: Η υλοποίηση της συνδεδεμένης λίστας.
-   **`Stack.java`**: Η διεπαφή για τη δομή της στοίβας (Stack).
-   **`StackImpl.java`**: Η υλοποίηση της στοίβας.
-   **`Queue.java`**: Η διεπαφή για τη δομή της ουράς (Queue).
-   **`QueueImpl.java`**: Η υλοποίηση της ουράς.
