# Μέρος Β: Εφαρμογή Ελέγχου Ετικετών HTML

Αυτό το πακέτο (`edu.aueb.ds.tagchecking`) περιέχει την εφαρμογή για τον έλεγχο της σωστής εμφώλευσης και ισορροπίας των ετικετών (tags) σε αρχεία HTML.

---

## 1. Περιγραφή Εργασίας

### Στόχος

Ο στόχος είναι η δημιουργία ενός προγράμματος (`TagChecking.java`) που διαβάζει ένα αρχείο HTML και επαληθεύει ότι οι ετικέτες του είναι σωστά "ισορροπημένες" και "εμφωλευμένες".
Σε κάθε αρχείο HTML, οι ετικέτες οριοθετούν τμήματα κειμένου. Μια ετικέτα ανοίγματος έχει τη μορφή <tag_name> ενώ η αντίστοιχη ετικέτα κλεισίματος είναι η </tag_name>. 
Κάποιες συνηθισμένες ετικέτες είναι οι `<body>`, `<h1>` (επικεφαλίδα), `<p>` (παράγραφος), `<b>` (έντονη γραφή), κ.λπ.
Η ισορροπία σημαίνει ότι για κάθε ετικέτα ανοίγματος πρέπει να υπάρχει μια αντίστοιχη ετικέτα κλεισίματος. 
Η σωστή εμφώλευση σημαίνει ότι πρέπει να κλείσει πρώτα η τελευταία ετικέτα που άνοιξε προτού κλείσουν οι υπόλοιπες.

### Ειδικοί Κανόνες

-   **Μορφή Ετικετών:** Μια ετικέτα ανοίγματος έχει τη μορφή `<tag_name>` και η αντίστοιχη ετικέτα κλεισίματος είναι `</tag_name>`.
-   **Αυτο-κλειόμενες Ετικέτες:** Ετικέτες που εξ ορισμού δεν έχουν αντίστοιχη ετικέτα κλεισίματος, όπως οι `<br>` και `<img>`, πρέπει να αγνοούνται και να μην προκαλούν σφάλματα.

---

## 2. Ανάγνωση και Ανάλυση Αρχείου Εισόδου

Για την ανάγνωση του αρχείου HTML, η προτεινόμενη προσέγγιση είναι η χρήση των κλάσεων `java.io.BufferedReader` και `java.io.FileReader` για την αποδοτική ανάγνωση του αρχείου γραμμή προς γραμμή.

**Γενικά Βήματα που πρέπει να σκεφτείτε:**

1.  **Διάβασμα Γραμμών:** Πώς μπορείτε να διαβάσετε το αρχείο γραμμή προς γραμμή μέχρι να φτάσετε στο τέλος του;

2.  **Εντοπισμός Ετικετών:** Αφού έχετε μια γραμμή ως `String`, πώς μπορείτε να τη διατρέξετε για να εντοπίσετε την αρχή (`<`) και το τέλος (`>`) μιας ετικέτας;
    *   Μέθοδοι της κλάσης `String` όπως η `indexOf()` μπορούν να σας βοηθήσουν να βρείτε το ταίρι για κάθε `<`.

3.  **Απομόνωση Ετικέτας:** Πώς θα απομονώσετε το περιεχόμενο της ετικέτας (π.χ., "body", "/p") ως ένα νέο `String` για περαιτέρω επεξεργασία;

4.  **Χειρισμός Σφαλμάτων:**
    *   Τι θα πρέπει να συμβεί αν το αρχείο που δόθηκε ως όρισμα δεν υπάρχει (`IOException`);
    *   Τι θα γίνει αν μια ετικέτα ανοίξει αλλά δεν κλείσει ποτέ μέσα στην ίδια γραμμή (π.χ., `<b>Hello`); Το πρόγραμμά σας πρέπει να μπορεί να το χειριστεί αυτό.

**Σκελετός Κώδικα ως Αφετηρία:**

```java
try (BufferedReader reader = new BufferedReader(new FileReader(filePath))) {
    String line;
    int lineNumber = 0;
    while ((line = reader.readLine()) != null) {

        // Η λογική για τη σάρωση της γραμμής και τον εντοπισμό των '<' και '>' έρχεται εδώ...
                // Πώς θα βρείτε το αντίστοιχο '>' και θα απομονώσετε την ετικέτα;
    }
} catch (IOException e) {
    // Εδώ μπορείτε να χειριστείτε σφάλματα που σχετίζονται με το αρχείο.
}
```

## 3. Απαιτήσεις Εξόδου και Διαχείριση Σφαλμάτων

Το πρόγραμμα πρέπει να εντοπίζει και να αναφέρει το **πρώτο** σφάλμα που συναντά, τερματίζοντας αμέσως μετά.

1.  **Λανθασμένη Σειρά Κλεισίματος (Mismatched Tag):**
    -   **Σενάριο:** Μια ετικέτα κλεισίματος δεν ταιριάζει με την πιο πρόσφατη ετικέτα ανοίγματος. (π.χ., `<b><i></b></i>`)
    -   **Έξοδος:** `Error at line X: Mismatched tag. Expected </Y>, but found </Z>.`

2.  **Ετικέτα Κλεισίματος χωρίς Ταίρι (Closing Tag with No Match):**
    -   **Σενάριο:** Βρίσκεται μια ετικέτα κλεισίματος ενώ δεν υπάρχει καμία ανοιχτή ετικέτα. (π.χ., `</p>`)
    -   **Έξοδος:** `Error at line X: Found closing tag </Y> with no matching opening tag.`

3.  **Μη Κλεισμένες Ετικέτες στο Τέλος του Αρχείου (Unclosed Tags at EOF):**
    -   **Σενάριο:** Το πρόγραμμα φτάνει στο τέλος του αρχείου, αλλά μία ή περισσότερες ετικέτες παραμένουν ανοιχτές.
    -   **Έξοδος:** `Error: Reached end of file, but the following tags were not closed: [tag1, tag2, ...]`

4.  **Επιτυχής Έλεγχos:**
    -   **Σενάριο:** Όλες οι ετικέτες είναι σωστά ισορροπημένες.
    -   **Έξοδος:** `The HTML file has balanced tags.`

> **Tip:** Για να δείτε το ακριβές μήνυμα εξόδου που αναμένεται για κάθε περίπτωση, μελετήστε το αρχείο `src/test/resources/tag_checker_test_cases/solutions.txt`.
