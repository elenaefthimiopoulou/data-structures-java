# Έλεγχος Υλοποίησης Αλγορίθμου Ταξινόμησης

Σε αυτόν τον φάκελο θα βρείτε τον κώδικα για να ελέγξετε την υλοποίηση του αλγορίθμου ταξινόμησης `Mergesort` στην κλάση `Sort`.

## Εκτέλεση του Test

Για να ελέγξετε την υλοποίησή σας, μπορείτε να εκτελέσετε την `main` μέθοδο του αρχείου `SortTestMain.java`.

### Οδηγίες Εκτέλεσης από τη Γραμμή Εντολών

1.  Βεβαιωθείτε ότι βρίσκεστε στον κεντρικό φάκελο του project (`DS_exercise_2_student`).
2.  Μεταγλωττίστε τον κώδικα του project εκτελώντας την παρακάτω εντολή:
    ```bash
    javac -d out/production/ src/main/java/edu/aueb/ds/sort/*.java src/test/java/edu/aueb/ds/sort/*.java
    ```
3.  Εκτελέστε τον κώδικα ελέγχου με την παρακάτω εντολή:
    ```bash
    java -cp out/production/ edu.aueb.ds.sort.SortTestMain
    ```
