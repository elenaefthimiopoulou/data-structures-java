# Ταξινόμηση

Αυτό το πακέτο περιέχει την υλοποίηση του αλγορίθμου ταξινόμησης.

## Sort.java

Η κλάση `Sort.java` είναι μια μερικώς υλοποιημένη έκδοση του αλγορίθμου Mergesort. Θα πρέπει να ολοκληρώσετε την υλοποίηση των παρακάτω μεθόδων:

-   `mergeSortRecursive(Node<Integer> head, int size)`: Η αναδρομική μέθοδος που χωρίζει τη λίστα σε δύο μισά και τα ταξινομεί.
-   `merge(Node<Integer> left, Node<Integer> right)`: Η μέθοδος που συγχωνεύει δύο ταξινομημένες λίστες σε μία.

Μπορείτε να βρείτε περισσότερες πληροφορίες στις διαφάνειες του μαθήματος και στο αρχείο `Sort.java` όπου υπάρχουν σχόλια με οδηγίες.
