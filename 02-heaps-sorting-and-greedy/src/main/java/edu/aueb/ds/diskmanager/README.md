# ΑΤΔ Δίσκου (Disk)

Σε αυτό το πακέτο, θα πρέπει να υλοποιήσετε την κλάση `Disk`, η οποία αναπαριστά έναν δίσκο αποθήκευσης.

## Απαιτήσεις

Η κλάση `Disk` θα πρέπει να έχει τα παρακάτω χαρακτηριστικά:

-   **Μοναδικό ID**: Κάθε αντικείμενο `Disk` θα πρέπει να λαμβάνει ένα μοναδικό, αυτόματα αυξανόμενο ID κατά τη δημιουργία του.
-   **Χωρητικότητα**: Ο κάθε δίσκος έχει σταθερή χωρητικότητα 1TB (1,000,000 MB).
-   **Λίστα Φακέλων**: Να περιέχει μια λίστα με όνομα `folders` για την αποθήκευση των μεγεθών των φακέλων.
-   **Μέθοδος `getFreeSpace()`**: Να επιστρέφει τον διαθέσιμο χώρο που απομένει στον δίσκο σε MB.
-   **Υλοποίηση `Comparable<Disk>`**: Να υλοποιεί τη διεπαφή `Comparable<Disk>` για να μπορεί να χρησιμοποιηθεί σε ουρά προτεραιότητας. Η σύγκριση πρέπει να γίνεται με βάση τον ελεύθερο χώρο.

## Οδηγίες

-   Δημιουργήστε το αρχείο `Disk.java` σε αυτό το πακέτο.
-   Υλοποιήστε την κλάση `Disk` σύμφωνα με τις παραπάνω απαιτήσεις.
-   Μπορείτε να προσθέσετε όποια άλλα πεδία ή μεθόδους θεωρείτε απαραίτητα.
