# Πειραματική Αξιολόγηση

Σε αυτό το πακέτο, θα πρέπει να υλοποιήσετε την πειραματική αξιολόγηση των αλγορίθμων "Greedy" και "Greedy-decreasing".

## Παρεχόμενες Κλάσεις

-   **`DataGenerator.java`**: Αυτή η κλάση είναι υπεύθυνη για τη δημιουργία των δοκιμαστικών δεδομένων.
-   **`ChartGenerator.java`**: Αυτή η κλάση δημιουργεί το γράφημα της σύγκρισης.
-   **`Result.java`**: Αυτή είναι μια βοηθητική κλάση για την αποθήκευση των αποτελεσμάτων.

## Αρχείο προς Υλοποίηση

-   **`ComparisonRunner.java`**: Θα πρέπει να δημιουργήσετε αυτή την κλάση, η οποία θα εκτελεί τη σύγκριση.

## Οδηγίες

1.  Δημιουργήστε την κλάση `ComparisonRunner.java`.
2.  Στη `main` μέθοδο της `ComparisonRunner`, θα πρέπει:
    -   Να καλέσετε τη `main` μέθοδο της `DataGenerator` για να δημιουργήσετε τα αρχεία δεδομένων.
    -   Να επαναλάβετε για κάθε τιμή του Ν και κάθε δοκιμαστικό αρχείο:
        -   Να εκτελέσετε τον αλγόριθμο `Greedy`.
        -   Να εκτελέσετε τον αλγόριθμο `GreedyDecreasing`.
        -   Να αποθηκεύσετε τα αποτελέσματα.
    -   Να υπολογίσετε τους μέσους όρους.
    -   Να καλέσετε τη `generateChart` της `ChartGenerator` για να δημιουργήσετε το γράφημα.
    -   Να αποθηκεύσετε τα αποτελέσματα σε ένα αρχείο `results.csv`.
