# Υλοποίηση Αλγορίθμων Greedy

Σε αυτό το πακέτο, θα πρέπει να υλοποιήσετε τους αλγορίθμους "Greedy" και "Greedy-decreasing".

## Αρχεία προς Υλοποίηση

1.  **`Greedy.java`**: Δημιουργήστε αυτή την κλάση και υλοποιήστε τον αλγόριθμο "Greedy" όπως περιγράφεται στο κεντρικό `README.md` του project. Η κλάση θα πρέπει να περιέχει μια `main` μέθοδο για να μπορείτε να την εκτελείτε μεμονωμένα για δοκιμές.

2.  **`GreedyDecreasing.java`**: Δημιουργήστε αυτή την κλάση και υλοποιήστε τον αλγόριθμο "Greedy-decreasing" όπως περιγράφεται στο κεντρικό `README.md` του project. Η κλάση θα πρέπει να περιέχει μια `main` μέθοδο για να μπορείτε να την εκτελείτε μεμονωμένα για δοκιμές.

## Οδηγίες

-   Ακολουθήστε τις οδηγίες στο κεντρικό `README.md` για τη λογική των αλγορίθμων.
-   Θα πρέπει επίσης να γράψετε τον δικό σας κώδικα για την πειραματική αξιολόγηση, ο οποίος θα χρησιμοποιεί τις κλάσεις που θα υλοποιήσετε εδώ.
