# Εργασία 2 - Ταξινόμηση και Ουρές Προτεραιότητας

## Εισαγωγή

Σκοπός της εργασίας αυτής είναι η εξοικείωση με τους αλγορίθμους ταξινόμησης και με τη χρήση ουράς προτεραιότητας, μία από τις πιο βασικές δομές δεδομένων στη σχεδίαση αλγορίθμων. Η εργασία αφορά ερωτήματα που συναντώνται σε προβλήματα βελτιστοποίησης σχετικά με την ανάθεση πόρων μνήμης για αποθήκευση δεδομένων μεγάλου όγκου.

### Το Πρόβλημα: Bin Packing

Το πρόβλημα που εξετάζουμε είναι μια παραλλαγή του κλασικού προβλήματος "Bin Packing". Στόχος μας είναι να αποθηκεύσουμε ένα σύνολο φακέλων (μεγεθών σε MB) σε δίσκους χωρητικότητας 1TB, ελαχιστοποιώντας τον αριθμό των δίσκων που χρησιμοποιούνται. Κάθε φάκελος πρέπει να αποθηκεύεται εξ ολοκλήρου σε έναν δίσκο.

Το πρόβλημα αυτό είναι NP-hard, που σημαίνει ότι δεν υπάρχει γνωστός αποδοτικός αλγόριθμος που να βρίσκει πάντα τη βέλτιστη λύση. Ωστόσο, μπορούμε να σχεδιάσουμε αποδοτικές ευρετικές μεθόδους (heuristics) που προσεγγίζουν τη βέλτιστη λύση. Σε αυτή την εργασία, θα υλοποιήσετε και θα συγκρίνετε δύο τέτοιες μεθόδους: τον "Greedy" και τον "Greedy-decreasing" αλγόριθμο.

## Μέρος Β: Αλγόριθμος "Greedy"

### Στόχος

Υλοποίηση του αλγορίθμου "Greedy" στο αρχείο `Greedy.java`. Θα πρέπει να υλοποιήσετε τη λογική του αλγορίθμου, όπως περιγράφεται παρακάτω.

### Λογική Αλγορίθμου

1.  **Επεξεργασία με τη σειρά**: Οι φάκελοι επεξεργάζονται ένας-ένας, με την ίδια σειρά που εμφανίζονται στο αρχείο εισόδου.
2.  **Τοποθέτηση στον πιο άδειο δίσκο**: Για κάθε φάκελο, ο αλγόριθμος αναζητά τον δίσκο που έχει ήδη χρησιμοποιηθεί και διαθέτει τον περισσότερο ελεύθερο χώρο. Αν ο φάκελος χωράει, τοποθετείται εκεί.
3.  **Δημιουργία νέου δίσκου**: Αν ο φάκελος δεν χωράει σε κανέναν από τους υπάρχοντες δίσκους, δημιουργείται ένας νέος δίσκος και ο φάκελος τοποθετείται σε αυτόν.

## Μέρος Δ: Πειραματική Αξιολόγηση

### Στόχος

Σε αυτό το μέρος, θα πρέπει να υλοποιήσετε την πειραματική σύγκριση των δύο αλγορίθμων. Σας δίνονται οι κλάσεις `DataGenerator.java`, `ChartGenerator.java`, και `Result.java` για να σας βοηθήσουν.

### Οδηγίες

1.  **Μελετήστε τις παρεχόμενες κλάσεις**:
    -   `DataGenerator.java`: Δημιουργεί τα αρχεία δεδομένων.
    -   `ChartGenerator.java`: Δημιουργεί το γράφημα.
    -   `Result.java`: Μια βοηθητική κλάση για την αποθήκευση των αποτελεσμάτων.

2.  **Υλοποιήστε την κλάση `ComparisonRunner.java`**:
    -   Δημιουργήστε μια νέα κλάση `ComparisonRunner.java` στο πακέτο `comparison`.
    -   Σε αυτή την κλάση, θα γράψετε τη λογική για την εκτέλεση της σύγκρισης, χρησιμοποιώντας τις παρεχόμενες κλάσεις.
    -   Η `main` μέθοδος της `ComparisonRunner` θα πρέπει να εκτελεί τα παρακάτω βήματα:
        1.  Να καλεί τη `main` της `DataGenerator` για να δημιουργήσει τα δεδομένα.
        2.  Να εκτελεί τους αλγορίθμους `Greedy` και `GreedyDecreasing` για κάθε αρχείο δεδομένων.
        3.  Να υπολογίζει τους μέσους όρους.
        4.  Να αποθηκεύει τα αποτελέσματα σε αρχείο `results.csv`.
        5.  Να καλεί την `ChartGenerator` για να δημιουργήσει το γράφημα.
