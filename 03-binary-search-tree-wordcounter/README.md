# Εργασία 3 - Μετρητής Λέξεων με Δέντρα Δυαδικής Αναζήτησης

## Εισαγωγή

Σκοπός της εργασίας αυτής είναι η εξοικείωση με τις δομές που χρησιμοποιούνται για την υλοποίηση πίνακα συμβόλων, όπως τα δέντρα δυαδικής αναζήτησης. Το ζητούμενο της εργασίας είναι να κατασκευάσετε ένα Μετρητή Λέξεων. Η βασική λειτουργία του μετρητή είναι ότι θα μπορεί να “φορτώνει” ένα αρχείο αγγλικού κειμένου και θα μετράει πόσες φορές εμφανίζεται η κάθε λέξη.

### Το Πρόβλημα: Μετρητής Λέξεων

Για παράδειγμα, στο κείμενο: 

- Hello, how are you? 
- Very well, thank you.

η λέξη "you" εμφανίζεται 2 φορές, ενώ οι λέξεις "hello", "how", "are", "very", "well", "thank" από μία φορά.

Ανάλογα με τη μέθοδο εκτύπωσης, η μορφή της εξόδου θα ήταν:

**Αλφαβητική Ταξινόμηση (`printTreeByWord`)**
```text
are: 1
hello: 1
how: 1
thank: 1
very: 1
well: 1
you: 2
```

**Ταξινόμηση κατά Φθίνουσα Συχνότητα (`printTreeByFrequency`)**
```text
you: 2
are: 1
hello: 1
how: 1
thank: 1
very: 1
well: 1
```

### Κανόνες Επεξεργασίας Λέξεων

Η επεξεργασία του κειμένου από τη μέθοδο `load` ακολουθεί συγκεκριμένους κανόνες που εφαρμόζονται σε κάθε συμβολοσειρά του αρχείου εισόδου:

*   **Case-Insensitive**: Όλες οι λέξεις μετατρέπονται σε πεζά.
    *   *Παράδειγμα*: Οι `Hello` και `hello` θεωρούνται η ίδια λέξη.

*   **Επεξεργασία Χαρακτήρων**: Διατηρούνται μόνο τα γράμματα του αγγλικού αλφαβήτου και ο χαρακτήρας της παύλας (`-`). Όλοι οι άλλοι χαρακτήρες (σημεία στίξης, αριθμοί, κ.λπ.) αφαιρούνται.
    *   *Παράδειγμα*: Η φράση `(well, thank-you!)` δίνει τις λέξεις `well` και `thank-you`.

*   **Υποστήριξη Stop Words**: Παρέχεται η δυνατότητα ορισμού μιας λίστας από λέξεις (stop words) οι οποίες αγνοούνται πλήρως κατά την επεξεργασία.

    *   **Τι είναι τα Stop Words;**
        Πρόκειται για λέξεις που εμφανίζονται πολύ συχνά σε ένα κείμενο αλλά συνήθως δεν προσφέρουν σημαντική πληροφορία για το περιεχόμενό του (π.χ., άρθρα, προθέσεις, σύνδεσμοι όπως `the`, `is`, `in`, `and`).

    *   **Πώς λειτουργεί ο μηχανισμός;**
        1.  Η λίστα των stop words είναι αρχικά κενή.
        2.  Η μέθοδος `addStopWord(String w)` χρησιμοποιείται για να προσθέσει λέξεις σε αυτή τη λίστα.
        3.  Κατά την εκτέλεση της `load(String filename)`, κάθε λέξη που εξάγεται από το κείμενο ελέγχεται: αν ανήκει στη λίστα των stop words, αγνοείται πλήρως και δεν εισάγεται στο δέντρο.
        4.  Αυτό διασφαλίζει ότι ο μετρητής εστιάζει μόνο στις σημαντικές λέξεις του κειμένου.

*   **Φιλτράρισμα Μήκους**: Λέξεις με μήκος 1 ή 0 χαρακτήρες μετά την επεξεργασία αγνοούνται.

*   **Αφαίρεση Κτητικής Απόστροφου**: Η κατάληξη `'s` αφαιρείται από το τέλος των λέξεων.
    *   *Παράδειγμα*: Το `student's` μετατρέπεται σε `student`.

*   **Διαχωρισμός με `/`**: Ο χαρακτήρας `/` αντιμετωπίζεται ως κενό.
    *   *Παράδειγμα*: Το `read/write` επεξεργάζεται ως δύο λέξεις, `read` και `write`.

## Μέρος Α: Υλοποίηση Βασικών Κλάσεων

### Στόχος

Για την υλοποίηση του μετρητή λέξεων, χρειαζόμαστε δύο βασικές κλάσεις:

-   **`WordFrequency.java`**: Για κάθε μοναδική λέξη που εντοπίζεται στο κείμενο, δημιουργείται ένα αντικείμενο αυτής της κλάσης. Περιέχει τουλάχιστον δύο πεδία: την ίδια τη λέξη (`private String`) και το πλήθος των εμφανίσεών της (`private int`). Η κλάση υλοποιεί τη μέθοδο `key()` που επιστρέφει τη λέξη (το κλειδί), ενώ η υλοποίηση της `toString()` διευκολύνει την εκτύπωση των αποτελεσμάτων.

-   **`TreeNode.java`**: Αναπαριστά έναν κόμβο του Δέντρου Δυαδικής Αναζήτησης και υλοποιείται ως ιδιωτική κλάση (`private class`) μέσα στον πίνακα συμβόλων. Κάθε αντικείμενο `TreeNode` περιέχει:
    -   **`item`**: Ένα αντικείμενο τύπου `WordFrequency` που αποθηκεύει τη λέξη και τη συχνότητά της.
    -   **`left`, `right`**: Δύο δείκτες (`TreeNode`) προς το αριστερό και το δεξί παιδί αντίστοιχα.
    -   **`subtreeSize`**: Ένας ακέραιος (`int`) που δηλώνει το πλήθος των κόμβων στο υποδέντρο που ξεκινά από τον τρέχοντα κόμβο (συμπεριλαμβανομένου του ιδίου).

    Η δομή της κλάσης περιγράφεται παρακάτω:
    ```java
    private class TreeNode {
        WordFrequency item;
        TreeNode left;      // pointer to left subtree
        TreeNode right;     // pointer to right subtree
        int subtreeSize;    // number of nodes in subtree starting at this node
        // ...
    }
    ```
    Η πρόσβαση στο κλειδί του κόμβου (π.χ. για έναν κόμβο `h`) γίνεται μέσω της `h.item.key()`.

## Μέρος Β: Υλοποίηση του Πίνακα Συμβόλων

### Το Interface `WordCounter`

Το interface `WordCounter` περιέχει τις εξής 13 μεθόδους που πρέπει να υλοποιήσετε στην κλάση `BST.java`.

### Λειτουργικότητα Μεθόδων

-   **`insert(String w)`**: Αναζητά αν υπάρχει ήδη στο δέντρο κόμβος με κλειδί `w`. Αν ναι, αυξάνει τη συχνότητά του κατά 1. Διαφορετικά, εισάγει έναν νέο κόμβο (ως φύλλο) με κλειδί `w` και συχνότητα 1.
-   **`search(String w)`**: Αναζητά στο δέντρο τη λέξη `w`. Αν δεν υπάρχει, επιστρέφει `null`. **Βελτιστοποίηση**: Αν η λέξη βρεθεί και η συχνότητά της είναι μεγαλύτερη από τη μέση συχνότητα (`getMeanFrequency()`), ο κόμβος της μεταφέρεται στη ρίζα του δέντρου με χρήση περιστροφών. Αυτό επιταχύνει μελλοντικές αναζητήσεις για συχνές λέξεις.
-   **`remove(String w)`**: Αφαιρεί από το δέντρο τον κόμβο με κλειδί `w`, αν αυτός υπάρχει.
-   **`load(String filename)`**: Διαβάζει ένα αρχείο κειμένου και ενημερώνει το δέντρο με τις λέξεις του, τηρώντας όλους τους κανόνες επεξεργασίας.
-   **`getNumTotalWords()`**: Επιστρέφει το συνολικό πλήθος των λέξεων στο κείμενο. Για βέλτιστη απόδοση, η υλοποίηση πρέπει να επιστρέφει μια προ-υπολογισμένη τιμή (cached) σε χρόνο **O(1)**.
-   **`getNumDistinctWords()`**: Επιστρέφει το πλήθος των μοναδικών (διαφορετικών) λέξεων. **Απαίτηση**: Η εκτέλεση πρέπει να έχει πολυπλοκότητα **O(1)**.
-   **`getFrequency(String w)`**: Επιστρέφει τη συχνότητα εμφάνισης της λέξης `w`. Αν η λέξη δεν υπάρχει, επιστρέφει 0.
-   **`getMaxFrequency()`**: Επιστρέφει το αντικείμενο `WordFrequency` που αντιστοιχεί στη λέξη με τη μεγαλύτερη συχνότητα.
-   **`getMeanFrequency()`**: Υπολογίζει και επιστρέφει τη μέση συχνότητα εμφάνισης.
-   **`addStopWord(String w)`**: Προσθέτει τη λέξη `w` στη λίστα των stop words. **Απαίτηση**: Η εκτέλεση πρέπει να έχει πολυπλοκότητα **O(1)**.
-   **`removeStopWord(String w)`**: Αφαιρεί τη λέξη `w` από τη λίστα των stop words.
-   **`printTreeByWord(PrintStream stream)`**: Εκτυπώνει τις λέξεις του δέντρου και το πλήθος εμφανίσεων κάθε λέξης, ταξινομημένες με αλφαβητική σειρά.
-   **`printTreeByFrequency(PrintStream stream)`**: Εκτυπώνει τις λέξεις του δέντρου και το πλήθος εμφανίσεών τους, ταξινομημένες κατά φθίνουσα συχνότητα. Σε περίπτωση ισοβαθμίας στη συχνότητα, οι λέξεις ταξινομούνται αλφαβητικά.

### Οδηγίες Υλοποίησης

1.  **Υλοποίηση `ListImpl.java` (Tailed Linked List)**
    *   **Στόχος**: Πριν ξεκινήσετε με το Δέντρο, πρέπει να ολοκληρώσετε την υλοποίηση της συνδεδεμένης λίστας στο αρχείο `src/main/java/edu/aueb/ds/datastructures/ListImpl.java`.
    *   **Απαίτηση**: Για να πετύχετε την πολυπλοκότητα **O(1)** για την `addStopWord`, πρέπει να υλοποιήσετε σωστά τη λογική του δείκτη `tail`. Ακολουθήστε τα σχόλια `// TODO:` μέσα στο αρχείο.

2.  **Υλοποίηση `BST.java` (Binary Search Tree)**
    *   **Στόχος**: Αυτή είναι η κύρια κλάση της εργασίας. Εδώ πρέπει να υλοποιήσετε όλες τις παραπάνω μεθόδους του `WordCounter` interface.
    *   **Οδηγίες**: Ακολουθήστε τα σχόλια `// TODO:` μέσα στο αρχείο `src/main/java/edu/aueb/ds/wordcounter/BST.java` για να συμπληρώσετε τη λογική που λείπει.

## Μεταγλώττιση και Εκτέλεση

Για τη μεταγλώττιση και την εκτέλεση του project από τη γραμμή εντολών, βεβαιωθείτε ότι βρίσκεστε στον φάκελο `DS_exercise_3_student` και ακολουθήστε τα παρακάτω βήματα.

### Βήμα 1: Μεταγλώττιση Κώδικα Εφαρμογής

Αυτή η εντολή θα μεταγλωττίσει τον κύριο κώδικα της εφαρμογής και θα τοποθετήσει τα αρχεία `.class` στον κατάλληλο φάκελο εξόδου (`out/production`).

```bash
   javac -d out/production src/main/java/edu/aueb/ds/datastructures/*.java src/main/java/edu/aueb/ds/wordcounter/*.java
```

### Βήμα 2: Μεταγλώττιση Κώδικα Ελέγχου (Tests)

Αυτή η εντολή θα μεταγλωττίσει τον κώδικα ελέγχου, συνδέοντάς τον με τον ήδη μεταγλωττισμένο κώδικα της εφαρμογής.

```bash
   javac -d out/test -cp out/production src/test/java/edu/aueb/ds/wordcounter/*.java
```

### Βήμα 3: Εκτέλεση των Tests

Μόλις ολοκληρώσετε την υλοποίησή σας, μπορείτε να την ελέγξετε εκτελώντας τις κλάσεις ελέγχου. Ο χαρακτήρας `:` στο classpath λειτουργεί σε Linux/macOS. Για Windows, αντικαταστήστε τον με `;`.

**Βασικά Tests:**
```bash
   java -cp out/production:out/test edu.aueb.ds.wordcounter.WordCounterComprehensiveTest
```

**Tests με Πραγματικά Δεδομένα:**
```bash
   java -cp out/production:out/test edu.aueb.ds.wordcounter.WordCounterTest
```

Όταν η υλοποίησή σας είναι σωστή, όλα τα tests θα πρέπει να περνούν με επιτυχία.
